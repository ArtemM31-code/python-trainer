# 🐍 Интерактивный Тренажёр Python (Python Trainer Web IDE)

Современная веб-платформа для изучения и отработки навыков программирования на Python с живым выполнением кода, автопроверкой тестами и интерактивным редактором на движке **Monaco Editor** (как в VS Code).

---

## 🌟 Основные возможности

- 💻 **Полноценный Web IDE**: встроенный редактор Monaco с подсветкой синтаксиса Python, автодополнением и горячими клавишами (`Ctrl + Enter` — запуск, `Ctrl + Shift + Enter` — проверка).
- ⚡ **Мгновенный запуск кода**: безопасное локальное выполнение скриптов с выводом `stdout` и `stderr`.
- 🧪 **Автоматическое тестирование задач**: проверка решений скрытыми и открытыми тестами с наглядной визуализацией результатов.
- 📚 **Библиотека практических заданий**:
  1. Основы Python (переменные, типы, срезы, f-строки)
  2. Структуры данных (списки, словари, множества, списковые включения)
  3. Функции (`def`, аргументы, возвращаемые значения, аннотации типов)
  4. Распаковка аргументов (`*args` и `**kwargs`)
  5. Области видимости LEGB и замыкания (`closures`, `nonlocal`)
  6. Декораторы (простые декораторы, декораторы с аргументами, `functools.wraps`)
  7. Обработка ошибок (`try / except / else / finally`, кастомные исключения)
  8. Объектно-ориентированное программирование (ООП: классы, методы, свойства, наследование)
- 📊 **Сохранение прогресса**: автоматическое сохранение прогресса и написанного кода.
- 🎨 **Современный тёмный UI**: чистый интерфейс, поддержка изменения размеров панелей, адаптивность.

---

## 🏗 Архитектура и разработка субагентами

Проект разработан мультиагентной системой:
- 👑 **Главный агент (Orchestrator)**: архитектурный надзор, спецификация контрактов API, интеграция, код-ревью и сборка проекта.
- ⚙️ **Backend-агент**: разработка REST API на **FastAPI**, изолированного раннера выполнения кода на `subprocess`, системы валидации тестов и хранилища прогресса.
- 🖥️ **Frontend-агент**: создание интерфейса с раздельными панелями (Split-pane), интеграция редактора Monaco Editor через CDN, логика консоли и карточек результатов тестирования.
- 📖 **Content & QA-агент**: разработка обучающих модулей с теорией, практическими задачами, подсказками и автотестами, а также интеграционных тестов `pytest`.

## 🚀 Быстрый старт

### Требования
- Python 3.10+ (протестировано на Python 3.12)
- Браузер (Chrome, Edge, Firefox, Safari)

### Запуск в один клик (Windows)
Просто дважды кликните по файлу:
```bat
start.bat
```
Скрипт автоматически проверит зависимости, запустит веб-сервер и откроет тренажёр в браузере по адресу `http://127.0.0.1:8000`.

### Запуск вручную через терминал
```bash
# 1. Установка зависимостей
pip install -r requirements.txt

# 2. Запуск приложения
python run.py
```

### Запуск тестов
```bash
pytest backend/tests/
```

## 🐙 Инструкция по отправке в GitHub

Чтобы отправить проект в свой удалённый репозиторий на GitHub:

1. Создайте новый пустой репозиторий на [GitHub.com](https://github.com/new) (например, `python-trainer`).
2. В терминале в папке `C:\Users\тема\Desktop\python-trainer` выполните:
```bash
git remote add origin https://github.com/ВАШ_ЛОГИН/python-trainer.git
git branch -M main
git push -u origin main
```
*Все файлы проекта уже добавлены в локальный репозиторий и закоммичены.*
